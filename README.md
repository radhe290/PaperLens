# PaperLens

Research Companion AI that helps users understand research papers through AI-powered summarization, question answering, flashcards, and quizzes.

---

## Features

### Current Features
- PDF Upload
- PDF Text Extraction

### Planned Features
- AI Summarization
- Chat with Paper
- Flashcard Generation
- Quiz Generation
- User Authentication
- Research Roadmap Generation

---

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### AI & NLP
- Gemini API
- ChromaDB (planned)

## Setup Instructions

### Clone Repository

git clone <repo-url>

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
npm install
npm start
